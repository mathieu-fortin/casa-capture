Casa capture

A browser extension for Firefox and Chrome

It reads the property pages you open and posts what they already publish to your own Casa, on your own network.

It does nothing on its own. Casa is self-hosted software, and this is its companion. Without a Casa instance you can reach and a token from it, this extension has nowhere to send anything and will sit there doing nothing. That is the design, not a limitation.

What it does, and what it will not do

It makes no requests of its own to any property site. There is exactly one fetch() in the whole extension, and its address is the one you type into the options page. The script that runs on the sites contains no fetch, no XMLHttpRequest, no sendBeacon and no dynamic import — a test in Casa's own suite asserts exactly that on every commit, rather than promising it here.

The sites this covers sit behind an anti-bot tenancy and refuse an automated fetch. A served block is a stop signal, so nothing here tries to get past it: the page in front of you was fetched by you, browsing, as you were going to anyway.

It extracts nothing clever. It collects the page's own machine-readable evidence and sends it verbatim; all the understanding lives in Casa. So when a site redesigns, the fix is a parser edit and a replay over everything ever captured — you do not reinstall anything and you do not re-browse a fortnight of listings.

It shows you a queue. It never works one. The options page lists the pages your Casa says would tell it the most, best first, with the reason attached. Every one of them opens because you clicked it. The code contains no way to open one, and a test greps every script and fails if one appears.

Install

Firefox — desktop and Android

Download the .xpi from the latest release. It is signed by Mozilla, so it installs into ordinary release Firefox and updates itself from then on.

On desktop, opening the link in Firefox is enough. On Android there is no web install: save the file, then Settings → Add-ons → Install add-on from file.

Then, and this catches everybody: Firefox treats host permissions as opt-in. Open Add-ons → Casa capture → Permissions and allow access to the sites. Until you do, it sits there doing nothing, which looks exactly like it being broken.

Chrome, Edge or Brave — desktop only

Chrome blocks extensions from every source but its own Web Store, so there is no one-click install and there cannot be one until this is published there. Download the .zip from the latest release, unzip it somewhere permanent, open chrome://extensions, turn on Developer mode, and use Load unpacked.

Two consequences are permanent rather than teething problems: Chrome shows a "Disable developer mode extensions" warning at every start, and nothing auto-updates.

Chrome on Android cannot run this, or any extension. Use Firefox.

Privacy

It sends data to one address: the one you configure. The author operates no server and receives nothing. Read the full policy.
